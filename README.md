这是 2026-08-26 制作的剪辑演示，组合产品说明、界面截图、许可素材与旁白，**不是不间断的现场推理录像**。界面截图反映制作时的本地版本，不代表当前服务器在线状态。真实模型观测证据来自 MiniCPM-o 4.5 与昇腾 A2/vLLM-Ascend；不能用来声称已完成 910C/llama.cpp-omni 指定环境复现。

视频内统计为固定十类授权/代理样本共 30 次真实观测：27 次既有原始观测，加 3 次 v6 定向复跑，统一应用 v6 策略重聚合。它不是 v6 全量重新推理，也不等同于真实校园多路、7×24 生产准确率。约 4 秒是离线样本分析管线指标，不是生产系统秒级告警保证。

CampusMind 的边界：AI 发现事件，不定义学生；AI 观察课堂，不评价教师。示例人物与学校并非本项目的客户或背书者，演示不对任何可识别人物作危险、违纪或责任判断。
